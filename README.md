# Social Delas · Protótipo

> Protótipo de apresentação feito para um cliente real: um site de venda de ingressos para a festa **Social Delas (2ª edição)**. Serviu para mostrar a proposta visual e o fluxo de compra antes de fechar o orçamento do sistema completo.

**Demonstração ao vivo:** https://cayohenriquemarianobernardo.github.io/social-delas-prototipo/

## O que o protótipo mostra

- Página do evento com a identidade visual da marca (logo, cores e imagens do cliente)
- Lotes de ingressos, cupom de desconto e fluxo de compra simulado com pagamento via PIX
- Área da cliente com login e ingressos comprados
- Painel da organização com vendas por dia, pedidos, check-in e criação de cupons

Tudo roda em uma única página HTML, sem back-end: os dados são fictícios e nenhum pagamento é processado.

## Próxima etapa

O sistema real prevê integração com gateway de pagamento, autenticação de usuárias, banco de dados e painel de administração completo.

## Executar localmente

Abra o `index.html` no navegador. Não há dependências nem etapa de build.
